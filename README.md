# Exact Moment Accounting for Cooldown Sampling

Code accompanying **Exact Moment Accounting for Cooldown Sampling through Expired-Group Elimination**.

The implementation evaluates integer likelihood moments of a cooldown-sampled Gaussian mixture. **U** is the counted reference recurrence; **E** eliminates the expired group and shares messages by amplitude sum. Both compute the same moment. The complete-query experiments also include **B**, the inexpensive deterministic bound portfolio described in the paper.

## Requirements

- Python 3.9 or newer on Linux or macOS.
- Python standard library only; no installation or data download is needed.

All instances are deterministic synthetic inputs. The original main experiments used Python 3.10.12, one Linux CPU thread and a 2 GiB process-scope memory limit.

## Quick start

From the repository root:

```bash
# Four small checks: interval primitives, independent path oracles,
# support counts, zero-matrix input, and exact rational serialization.
python3 reproduce.py qa --output runs/qa

# A small U/E example, including comparison of every row state.
python3 reproduce.py expansion --case L96 --repetitions 1 --output runs/example

# Additional regression tests and checks of the recorded paper results.
python3 -m unittest discover -s tests -v
```

Each command writes to a new output directory. Do not run Python with `-O`, since the numerical checks use assertions.

## Reproduce the experiments

```bash
# Fixed W3 certificate: epsilon = 0.657, delta = 1e-5, 80-digit intervals.
python3 reproduce.py certified --output runs/certified

# Six horizon, bandwidth, participation and row-varying configurations.
python3 reproduce.py expansion --output runs/expansion

# Complete B/U/E privacy queries: W0, W3 and W4 at three delta values.
python3 reproduce.py workload --output runs/workload

# Earlier six-case moment comparison, including the low-order N2 case.
python3 reproduce.py confirmation --output runs/confirmation
```

The default is three paired repetitions in the fixed experimental order. Use `--case L48`, `--case W0`, or `--case N2` to select a case, and `--repetitions 1` for a shorter run. `all` runs the four experimental suites. Run the QA command first. Full runs take several minutes, depending on the machine.

The runner starts each arm in a fresh process and records complete child-process CPU and wall time in `run.json`. It compares U/E moments, row states or privacy queries as appropriate. Full row-state files are removed after successful comparison; `--keep-traces` retains them. The default timeout is 180 seconds per worker, adjustable with `--timeout`. Linux workers use one CPU affinity and a 2 GiB address-space limit; macOS uses the time limit without that Linux memory setting.

## Included results

```bash
# Rebuild CSV tables directly from the recorded results; no experiment rerun.
python3 summarize.py
```

| Paper experiment | Configuration | Included records |
| --- | --- | --- |
| Equal-guarantee certificate | `configs/main.json`: B | Six interval results and paired CPU times |
| Horizon/bandwidth/participation | `configs/main.json`: six C cases | 36 moment results and per-row comparison summaries |
| Complete privacy queries | `configs/workload.json` | 27 B/U/E results, all three delta values |
| Earlier moment comparison | `configs/confirmation.json` | 36 timing/moment summaries, including N2 |

`results/derived/` contains the regenerated tables and all paired CPU values. The recorded median reductions are 43.217% for the certificate, 21.484–48.943% for the six expansion cases, and 57.104% for the W3 complete query. The earlier N2 result (−0.078%) and W0 result (0.940%) are included.

The package includes compact records and validation results. The original large row-state dumps remain in the experiment archive and are not included; the runner can generate new row states. Recorded timings retain the original measurement protocol. The portable launcher replaces the original server-specific orchestration, so newly measured times depend on the environment and launcher. Interval certification concerns the fixed ideal Gaussian-mixture pair in the paper; the other experiment suites use floating-point moment evaluation.

## Repository layout

```text
src/                U/E evaluators, interval arithmetic, independent oracles,
                    earlier implementations and privacy conversion
configs/            Fixed experimental inputs and execution order
results/paper/      Recorded numerical results and timing summaries
results/derived/    CSV tables regenerated by summarize.py
tests/              Regression and recorded-result checks
reproduce.py        Standalone experiment runner
summarize.py        Paper-table reconstruction
```

The numerical recurrences, kernels, interval primitives and portfolio formulas are retained from the experimental implementations. Packaging changes provide a portable launcher, portable resource checks, platform-correct RSS units, and an input check restricting the fixed certificate function to its intended W3 instance.
